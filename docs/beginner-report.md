# 一个八字初学者能看懂的最终报告

> 这份报告回答三个问题：**这套东西在干嘛？目前敢说什么？能拿来干什么？**
> 不用任何命理基础也能读完。术语第一次出现时都会翻译成人话。
> 2026-10-09 定稿。

---

## 一、先说定位：这不是"算命软件"，是一套"敢不敢说"的纪律

算命行业最常见的问题不是"算不准"，而是**说了你也没法验**：
"命里带官气，中年有贵人"——这句话对谁都能说，对谁都能圆。

这个项目干的事很朴素：**找 2300 多个真人案例，把各种说法拿去当真检验**，
然后规定**只有过了检验的说法才准说出口**，没过的说法要么标注"仅供参考"，要么直接撤下。

所以它产出的不是"预言"，而是一张**成绩单**：哪些说法站住了、哪些没站住、哪些压根没法检验。

---

## 二、三分钟扫盲：八字和"十神"

- **八字**：一个人出生的年、月、日、时，每个时刻用两个字表示（一个天干＋一个地支），
  总共八个字，例如 `丁卯 辛亥 戊子 癸丑`。天干是甲到癸这 10 个，地支是子到亥这 12 个。
- **日主**：八个字里、出生日那两个字的上一个字（上例是"戊"）。**整个盘以它为中心**，
  相当于"主语"。上例就是"戊命"。
- **十神**：把其它七个字跟"日主"的关系翻译成一个称呼。共 10 个称呼，比如：
  - 「财」类：**正财**（稳定收入、工资）、**偏财**（外快、生意、流动的钱）
  - 「官」类：**正官**（体制、职位、规矩）、**七杀**（压力、竞争、强权）
  - 「印」类：正印/偏印（学历、长辈、保护）
  - 「食伤」类：食神/伤官（才华、表达、输出）
  - 「比劫」类：比肩/劫财（兄弟朋友、同辈竞争）
  一句话：**八字是原文，十神是译文。** 这套系统读的是译文，也要经常回原文核。
- **藏干**：地支里"藏着"的天干。比如"辰"里藏着 戊、乙、癸。所以一个字可能要算成两三个十神。

## 三、项目做了什么（四步）

1. **攒料**：从多个来源收 2322 个案例（古今都算），每个案例都尽量保留原始记录。
2. **转译**：把每个案例的八字算成"十神计数"（比如"偏财 3 个、正官 0 个"），并给盘贴上"机制标签"
   （例如"杀印相生"这种组合），全部机器生成、不手抄。
3. **检验**：对每条想说的规则，问三个问题——
   - 样本够不够多？（人多才算数）
   - 会不会是碰巧？（同时检验十几种说法，就得把"算数"的门槛提高）
   - **换一半案例重算还成立吗？**（一半发现、一半验证，防自欺）
4. **分档**：结果按"敢说到什么程度"分成
   | 档 | 含义 |
   |---|---|
   | **A 档** | 敢说。门槛：**事前**登记、到期核对，真命中过 ≥2 次 |
   | **B 档** | 库内最强，但**没经过事前检验**，只能说"数据看着强" |
   | **C 档** | 解释得住（跟老书/口诀对得上），但没检验过 |
   | **D 档** | 禁止使用。话太虚、或者检验方式有循环论证 |

> 关键纪律：**A 档要求"事前说、事后核"**。看完答案再说"我早说过"，不算数。

## 四、成绩单（说人话版）

### 🥈 B 档（库里唯一一条"看着真的强"）
**「八字里偏财偏多的人，财的等级偏高」**
- 两条独立路径都对得上：回复层 +2.58、原始素材层 +2.98；
- 做成"0/1/2/3 个偏财"的梯度看，越多个越偏向高财级（z=+3.30），**不是被一两个极端案例带出来的**；
- 但**最强的那一半单独算只有 +2.06，没到线**（红线随检验数变成 2.86）；
- 也**从没经过"事前预测"检验**。
⇒ 所以它只能挂 B 档：**"数据看着强，还没被现实打过分"**。

### 🏅 A 档：**当前是空的**
- 不是没努力，是门槛硬：要"事前登记过的预测命中 ≥2 次"。目前挂着 6 条事前预测（最早 11 月初到期），命中 **0**。
- **A 档空集是诚实的结果，不是失败**——它说明这套系统确实在用最严的尺子量自己。

### ❌ 看着有、但过不了关的
- **正官 → 功名**：统计出来是"负相关"（正官多反而功名等级低），**跟常识反着**。在弄明白之前，**不许引用**。
- 正财、官印相生、伤官等：两条路径都过不了线。

### 🚫 检验不了的（不是没规律，是数据形式不允许）
- **六亲**（父母/兄弟）：等级区分度只有 0.19，几乎等于没有——**它是"是/否"的事实（父母在不在），不是"几等级"**。
- **刑灾官非**：几乎全是有：二元事实，做不出等级。
- **岁运应期**（哪年出事）：库里只有 47 条事件、25 例，样本太少，测不动。
- **口诀库**（1817 条）：每条只对应"某日柱×某月令"，平均只剩 3 个案例，统计上测不出。

## 五、自审发现（这套系统自己查自己）

### 1. 盘面计算：**可信**
我用一张**自己抄的**藏干表 + **自己写的**十神函数，把 2322 个盘从头重算一遍，跟库里的结果对比：
**2322/2322 完全一致**（三个口径都一致）。也就是说，"从八字算十神"这一步没毛病。

### 2. 抽取/配对：**有可量化的错（约 24%）**
- 命理规则：**阳年生的男性、阴年生的女性 → 大运顺排；其余逆排**。
- 库里能比的 375 例中，**90 例（24%）跟规则对不上**。
- 那是不是规则错了？我直接去翻**原始记录**：原文自己写的"四柱＋大运"共 560 处，**552 处（99%）符合规则**。
- ⇒ **规则没问题，错在我们把"盘"和"运"配到一起的时候配错了。**（此前只知道素材配错率 8.4%，这次从完全不相干的角度又测出 24%。）

**影响**：库级统计（几千个案例一起算）基本不受影响；但**"具体这一个人的盘"**的判断，必须先核三样东西：四柱、性别、大运方向。

### 3. 我自己也错过，如实记录
我曾写"起运最大约 5 岁"，并据此报告"548 例异常"。**错了。**
错因：把**「节」**跟**「节气」**搞混了——15 天是"节↔气"的距离，**节↔节是 30.4 天**。
正确上限是 **10.1 岁**，真正的异常只有 **14 例**。已撤回那份错误结论，并把教训写进了检查脚本的注释里。

## 六、普通人能拿走的三句话

1. **命理是路况图，不是判决书。** 这套检验做下来，能站住的规则少得可怜——
   任何跟你说"你注定如何"的人，都比你手里的这张成绩单更自信，但并没有更可靠。
2. **"说得越具体越准"是错觉。** 越具体的结论越难检验，所以越容易永远不被推翻。
3. **概率≠宿命。** 我们唯一站得住的结论也只是"偏财多的人**倾向**财级偏高"——是个概率倾斜，不是命运条文。

```bash
cd /home/ubuntu/projects/jinxiang-kucun

# 1) 找"结构相似"的案例（按盘的结构找，不按书里的编号找）

python3 scripts/case_search.py --case-id 5 --tags 杀印相生 --ri 戊       # 参考盘＋硬过滤＝按相似度排序

# 2) 查分档结论（唯一入口；册子里没有的＝还没到能说的档位）
cat distill/conclusions-register.md

# 3) 自审（只读，跑完就知道数据有没有新病）
python3 scripts/self_review.py --md distill/self-review-latest.md
```
