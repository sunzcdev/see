# 第三批上机：性别列修复 + 女命轴复测（干净池上全灭）

日期：2026-10-07　｜　库：`jinxiang.db`（2322 例）　｜　脚本：`rebuild_gender.py`、`arbitrate_gender.py`

## 0 · 结论先行

原 `case_features.gender` 是**病列**（每批第一例的性别盖全批）。修好后坤造池从每半 8~16 例涨到 28~88 例，
**女命轴（AX-09）五条在干净池上全平**；当年排名第一的「伤官见官→婚姻↓（坤造）」+2.12 掉到平
——**那是脏池造的假信号**。同时解冻两条因比肩计数错而「测不动」的条目（解冻后都是平）。

## 1 · 发现病列：三把尺子对裁

| 两把尺子 | 一致率 | n |
|---|---|---|
| 库 gender vs 块内「观此/观其+乾坤」 | **64.8%** | 193 |
| 库 gender vs 块内文义线索（克夫/嫁… vs 娶妻/岳父…） | **59.4%** | 96 |
| **乾坤直读 vs 文义线索（互不看对方）** | **98.9%** | 629 |

两个互相独立的读数 98.9% 一致，而库只跟它们 60% ⇒ **脏的是库，不是正文**。人眼复核 3 条不符例全部同向：

| 案例 | 库 | 正文（原文首段） |
|---|---|---|
| 144 | 坤 | 「**观其乾命**」，丁亥日元双戊夹泄… |
| 241 | 乾 | 「**观此坤命**…坤命以夫贵为荣…嫁夫也贵」 |
| 880 | 乾 | 「**坤**：丁辛乙丙酉亥酉戌…**观此坤命之造**…必克夫之命…做小妾」 |

### 病列指纹（一眼判据）

```
批内性别是否混合：旧列 单值批 215 / 混合批 0
                  新列 单值批 183 / 混合批 324
```
含 ≥2 例的批次里**零个混合** —— 真数据不可能。⇒ 抽取器取了每批第一例的性别盖给全批。
旧 vs 新在双有值例上不一致 **34.8%**（≈ 每批后几例被错标的比例）。

## 2 · 修复器做法

- **锚点＝四柱**，不是编号。坑：库内 `case_no=97` 的四柱（丙寅 庚寅 辛卯 辛卯）与同批正文
  「===== 例97 =====」的四柱（丙寅 庚寅 丁亥 癸卯）**不是同一造** ⇒ `case_no/例N` 已错位，只能用来分块。
- **两读**：`kq`＝块内「观此/观其+(乾|坤)+(命|造)」；`cue`＝块内文义线索（**不看乾坤二字**）。
- **定档**：两读一致 PASS ／ 只 kq → KQ ／ 只 cue → CUE ／ 冲突 CONFLICT ／ 都无 UNKNOWN。
- **落库**：新列 `gender_fixed` / `gender_grade` / `gender_evid`；原列另存 `gender_lib_orig` 留痕（不删，便于审计）。

覆盖：**PASS 1377 ｜ CUE 102 ｜ KQ 27 ｜ CONFLICT 7 ｜ UNKNOWN 809**（65.2%）→ 乾 927 / 坤 586。

### 坑：取窗跨到隔壁案例

v1 用「四柱前后 ±700 字」取窗读性别 ⇒ M1 准确率只有 **59.8%**。
根因：一个批次正文约 1000 字装 3 例，**窗口横跨到了隔壁案例**，读到的是别人的「观此坤命」。
v2 改为先按 `===== 例N =====` **切块**，块内锚四柱、块内读。

## 3 · 第二个坑：比肩恒 ≥1

AX09-03「身弱→婚姻↓」报「预测子无变异」。条件含 `比肩+劫财==0`，
而库口径把**日干自己**算进比肩（真比肩 = 库值 − 1）⇒ 该条件永远不成立。
打分器 `cnt()` 已改为 **比肩减 1**（`max(0, v-1)`）。

连带的解冻（原「测不动」→ 现在测了）：

| 条目 | 修复前 | 修复后 |
|---|---|---|
| AX03-03x（比劫==0 无印 → 刑灾↑） | 预测子无变异 | 平（G/B +1.56 单半） |
| AX03-04（财≥3 无比劫无印 → 财↓） | 预测子无变异 | 平（L B +1.38/+0.78） |
| AX02-04（比劫≥2 → 财↓） | 平 | 平（数值微动） |

> **线性 z 对计数整体平移免疫** ⇒ AX01-05（比肩线性）新旧逐字相同；
> 变化只出在「比劫求和后比较阈值（`==0` / `≥2`）」这类条件上。

## 4 · 女命轴（AX-09）干净池复测：五条全平

坤命池 586 例；有婚姻域结局者 源A 28/半、源B 73/半（旧脏池同口径 8~16/半）。

| 条目 | 条件 | 新结果 |
|---|---|---|
| AX09-01 | 夫星透干不在日时 → 婚姻↓ | 全平 |
| AX09-02 | 官杀混杂 → 婚姻↓ | 全平 |
| AX09-03 | 身弱（无比劫无印）→ 婚姻↓ | 预测子无变异（条件极窄） |
| AX09-04 | 伤官见官 → 婚姻↓ ★ | 全平 |
| AX09-05 | 夫星不显（无官杀）→ 婚姻↓ | 全平 |

| 条目 | 旧（脏池） | 新（干净池） |
|---|---|---|
| AX02-03m 伤官见官→婚姻↓（坤） | G B **+2.12 ★**、G A +1.50 ★（榜首） | **平**（G B +0.83/−0.76） |
| AX01-08 伤官≥1→婚姻↓（坤） | 平（n=8/16） | 平（n=28/73，L A −2.04/+0.77 两半反向） |

**可检出线声明**：源B L 每半 n=73 ⇒ `2.8·√(2P₀(1−P₀)/n) ≈ 0.23 SD` ——
**中等以上效应可检出；<0.23 SD 的弱效应不能排除**。

**这一轮把「测不动」变成了「测了、没有」** —— 这是补性别字段的真正收益：
改的是**结论的性质**（从资料不足 → 无信号），不是结论的方向。

## 6 · 沉淀的纪律

1. **分组变量先查批内是否单值** —— 多例批次里 0 个混合 = 病列指纹。
2. **计数型预测子不只看有无 0 组，还要看它是不是恒 ≥1**（比肩含日主），恒值即死条件。
3. **取窗必须切成「案例块」** —— 批次正文一屏装 3 例，按字符距离取窗必跨到隔壁。
4. **编号不可当锚点** —— 四柱才是；编号只能用来分块。
5. **一支柱的「数据不足」与「无信号」要分开报** —— 修完数据后若仍平，结论性质变了（可以更硬地说「没有」）。
