# 示范与裁判（真实跑数）

方法总纲在 SKILL.md；这里放**两个已跑完的实例**：一个是「六步流程」的完整走法，一个是量表选型的数据裁判。

## 一、六步流程示范：官印相生

脚本：`scripts/compress_probe.py`（旧）/ 重跑用 `verdict_domains` 新版。

**第 1 刀 · 宽域（官星数）——压不动**

| 条件 | n | 吉 | 凶 |
|---|---|---|---|
| 全库基线 | 722 | 17.0% | 43.9% |
| 正官=0 | 513 | 17.3% | 43.5% |
| 正官=1 | 183 | 14.2% | 45.9% |

⇒ 正官=0 与基线**几乎完全一样** ⇒ **宽域上「官星」信息量为零**（控制论 5.4 活例）。
按旧做法到这里就该判「理论无效、撤回」。**按压缩法：域太宽，去切。**

**第 2 刀 · 切域（正官=1 再叠一个条件）——方向出现**

| 条件 | n | 凶 |
|---|---|---|
| 正官=1 且 **无印** | 116 | **52.6%** |
| 正官=1 且 **印≥1** | 67 | **34.3%** |

⇒ 差 **18.3pp**，方向与经典「官印相生、有印则化」完全一致。
细节有价值：**变的是「凶」率，不是「吉」率** ⇒ 印的作用是**避凶**，不是致吉。

**判定 = 🥈 B 档（待观察）**
- 两比例检验 **z = 2.39 > 1.96**（统计上达显著）
- 但**未过本库自设保守线**：`2.8×√(2·0.459·0.541/n)` ⇒ 每臂需 ≈117 例，现为 116 / 67 ⇒ 第二臂缺一半
- ⇒ **下一步是继续切域**（不是扩样）：再叠「印有无根」「印是否透干」「是否财坏印」，看凶率能否压到 25% 以下

**这次示范同时给出方法论的一条硬结论**：旧 `shishen_config` 只算天干 ⇒ 上面所有「印」都是**天干印**。
真正的「官印相生」必须看**地支印根**。**尺子不修，切多少刀都是错的。**

## 二、量表裁判：天干单尺 vs 干支并看

**判据 = 压缩法（哪个尺子把可能性空间压得更小）。**
20 个趋势检验 ⇒ **多重比较校正红线 z ≈ 2.81** + 分半复现。

| 候选 | 全样本 z | 分半(z) | 判定 |
|---|---|---|---|
| 劫财（天干尺）| 2.63 | 1.10 / 0.65 | **虚**（靠 n=10 的格子撑，半样本不到线）|
| 偏印（天干尺）| −2.23 | −2.76 / −0.44 | **不稳** |
| **偏财（8字尺）** | **−2.84** | **−1.82 / −2.25** | **成立** ✅ |

**成立的唯一一条**（财域凶率，基线 39.7%）：

```
偏财 8字口径:  0档 60%(47) → 1档 37%(82) → 2档 38%(61) → 3档 28%(47)   趋势 z=−2.84
偏财 天干口径: 0档 40%(161) → 1档 44%(66)                                   z=−0.44（测不出）
正财 8字口径:  0档 32%(56) → 1档 40%(83) → 2档 41%(64) → 3档 50%(34)   z=+1.59（同向未过线）
正财 天干口径: 0档 40% → 1档 38%                                            平的
```

**读法**：**偏财（流通/众人之财）越多 → 财域结果越好；正财（受制之财）越多 → 越耗身破财。**
两条经典区分**只在把地支藏干算进来后才可见**——天干口径两行全平。

### 裁定

1. **改，但不是「换」是「并排」，8 字尺立为主尺。**
   依据：①它在唯一可测的域上压出了天干尺压不出的梯度，过最严校正线 + 分半复现；
   ②纯天干尺与自家经典自相矛盾（子平取用神以月令=地支为准）；
   ③《千里命稿》韦千里「当以干支并看」——两套语义并存（天干=表面/显，地支=实力/根）。
2. **诚实面**：这是**单点证据**（1 域 × 1 十神），不是全面胜利。其余 17 个检验全灭，
   其中天干尺的 2 个疑似发现正是「20 次里该出现的假阳性」——**多重比较校正救了这一步**。
3. **暴露的真瓶颈**：多数事类被词表**单极化** ⇒ 详见 `library-status.md`。
4. **保留待验假设**：`tonggen`（根落哪一柱：年/月/日/时）是否比"有无根"更有效。
