## 结论

**当前第一优先不是写新理论，是把「强度」这一格做成真的。** 顺位：

1. ~~修 `shishen_config` → 8 字口径~~ **已办（2026-10-07）**

   完整调查见 `shishen-ruler-investigation.md`；裁判结论见 `worked-example.md`。
2. ~~修结果出口~~ **已办（2026-10-07）**

   实录见 `verdict-fix-and-ruler-verdict.md`。
3. **词表补双向**（新第一优先）——多数事类被单极化 ⇒ 结构性天花板：
   - 功名事业基线凶率仅 **3.9%**（几乎只有"显贵"才被记下）
   - 刑灾官非 **100% 凶**、寿元健康 **96.5% 凶**（词表只有凶向）
   ⇒ 目前只有「财」「婚姻」两域可用。词表不收双向，换多少把尺子都是白测。
4. **修 `law_case_link`**：关系改由**内容判据**定（supports / contradicts），废掉 `rzyl` 自匹配。
5. **建图谱**：把 `pattern_maps` 从 0 行填起来（＝四级抽象：字→十神→格局→用神）。
6. **批量过 1817 条铁律**：按六步流程填表 → 四档归位 → 得出「我们真正敢说的条目有多少条」。

## 意外收获：库里有回顾性应期数据

修好出口抽取后，`verdict_raw` 里出现的不是"结局词"，而是**带流年 + 大运的事件年表**：

```
庚申(1980)辛亥运肺病住院✅ 癸亥(1983)辛亥运眼疾失明✅ 戊寅(1998)庚戌运结婚✅
```

⇒ **案例库本身就存着「事件—流年—大运」三元组**，只是被旧白名单抽烂了。
这是前瞻账本之外的**回顾性应期数据**，后续可直接做「大运引动」检验。
