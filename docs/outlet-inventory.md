## 三、出口健康度闸（本轮新增）

规则（写进打分器，每轮自动打印）：

- **二值出口 X**：基线率 P0 落在 5%~95% 之外 ⇒ `退化(单极)`，**其上的 z 不可读**；15%~85% 之外 ⇒ `偏斜`。
- **序数出口 L / S**：档数 ≥3 且 H/Hmax ≥0.5 ⇒ `OK`；否则 `分辨率不足` / `集中`。
- **G（全局凶率）是代理出口**：它测的是「该例任意域见凶」，**不是靶域**。用 G 测靶域断语，结论只能算代理级。

全库实测退化出口：功名 X（4%）、寿元 X（96.5%）、六亲 X（100%）、刑灾官非 X（100%）；集中：婚姻 L·源A（H=0.47，均值 1.15）。

判例：13 条「两半一致」里，**4 条坐在退化出口上**（功名 X 只有 ~6 个事件）、**3 条坐在代理出口 G 上** —— 真正干净坐在健康靶域出口上的只剩 5 条。

## 五、S 出口（域内严重度）—— 换口径的合法姿势

单极化死锁的出路不是补词表，是**换口径**：把二值（吉/凶）换成序数（程度）。

- **条件化**：只在「有该域结局」的例内分轻重 ⇒ 回答的是「出事的那些人里谁更重」，**不是**「谁更容易出事」。降级必须写在断语里。
- **层级顺序先验**：按传统断语轻重定（口舌 < 官司 < 牢狱 < 刑伤血光），话从语料词汇普查来。
- **落地**：`case_severity(case_id, dom, sev)` 表 ＋ 打分器 `S` 出口。
- **源只有一层**：S 从原文事实段抽，**只有源 T 一个源** ⇒ S 结果最高只算「单源一致」，**不得**当跨源复现。
- 实测：刑灾官非 94 例 / 3 档 / H=0.59 ⇒ OK；六亲 130/135 单级 ⇒ 废；子女 42 例 / 2 档 ⇒ 分辨率不足。

## 六、状态以打分器为准（底账纪律）

`entry-list.md` 的状态栏由 `build_entry_list.py` 从 `score-splithalf.txt` **机器写入**；手写状态降级为「备注」，并生成「手写 vs 机器 漂移表」。

理由：手写状态曾僵住 20 条（跑了没回写）——条目册是「敢说清单」的底账，底账与实测脱钩就不可信。

本轮首次回写暴露：**15 条手写「有结果」的条目，现行口径全平／测不到**（旧数字来自别的口径或代理出口）；21 条手写滞后（无害）。

配套两处自愈：
- 打分器测过、册子没登记的编号（口径变体 x/m/y）→ 由本体克隆**自动补登**。
- 本体编号只以变体入册时（如只有 `AX01-07x`）→ `resolve()` **认领变体**，不误报「没测」。
