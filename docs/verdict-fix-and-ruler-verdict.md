# 出口修复 + 十神尺子裁判（2026-10-07 收尾）

## 一、为什么先修出口

用粗「凶率」当判据测不出尺子差异——**不是地支没用，是出口分辨率太低**。
测量学常识：**自变量尺子再准，出口糊成一坨也测不出东西；先修分辨率最低的那一端。**

旧 `case_features.verdict` 三个病：
1. **白名单外结局全丢**：抽取器用关键词表（身亡/离婚/判刑/发贵…），
   真实结局是「尚书」「贵至黄堂」「进士」这类词时全部落空（表外）；
2. **白名单词出现在无关位置即假命中**：例「职位**升**迁」→ 存成 `verdict='升'`；
3. **诀言诗句被当结局**：「阳火透出**富贵**清」里的"富贵"是口诀，不是断语。

⇒ 覆盖 31.1%（722/2322），且噪声大。

## 二、修复三步（脚本 `scripts/verdict_v4.py`）

**关键转向：不是"把结局抽得更准"，而是"保留整句、让分类器去读"。**
v3 试过抽结局短语 → 把日期换算（`农历X = 公历Y`）、大运序列（`王寅8→癸卯18→`）
全当结局抓走。**抽得越狠丢得越多。**

1. **段落优选**：方法论(3) > 断语回溯/先断后核/事实(2) > 重点发现(1) > 排盘核验(0)
2. **三重锚定位**（关键！）：
   - 例号直配 `例473`
   - **本批序号兜底** `例1/2/3` —— 批880 回复写"例1"但库里是全局号 174，
     两者四柱一致 ⇒ 回复用**本批局部编号**，只按例号匹配会全批失配
   - **四柱兜底**：回复里出现该例八字原文 `癸酉癸亥庚申丁亥`
3. **整句清洗**：剥 `"诀言诗句"`、`农历/公历日期`、`干支+数字 大运序列`、markdown 星号
4. **从句边界**：锚 → 下一个 `例N` **或换行**（取先到者）。
   旧版只切 `例N`，导致例926 的句子吞掉例928/929 的"死刑牢狱" → 假阳性。

**再分事类×极性**（不抽短语，直接在整句上打标）：

8 个事类 × 吉/凶：功名事业、财、婚姻、子女、寿元健康、六亲、刑灾官非、特殊。

两个分类器坑（都已修）：
- **子串误伤**：「不**缺钱**」被读成「缺钱」=凶 ⇒ 最长词优先 + 命中后**吞掉该跨度**（占位符顶替）
- **否定**：`不离婚`/`不贫`/`无灾` 先整体挖掉，再按吉处理

**结果**：断语原文覆盖 **83.8%**（1945/2322）；
分级结果 **38.0%**（883）——宁缺勿滥，未分级的基本是纯排盘核验行（`例871： = | 丁巳 壬子 丙午 己亥`，确实无断事结论）。

**新增列**：`verdict_raw`（整句）/ `verdict_domains`（事类×极性 JSON）/ `verdict_sect`（来源段落）/ `verdict_match`（锚类型）。旧 `verdict` **不动**。

## 三、新出口的意外收获：库里有应期数据

修好抽取后，`verdict_raw` 里出现的不是"结局词"，而是**带流年+大运的事件年表**：

```
庚申(1980)辛亥运肺病住院✅ 癸亥(1983)辛亥运眼疾失明✅ 戊寅(1998)庚戌运结婚✅
```

⇒ **案例库本身存着「事件—流年—大运」三元组**，只是被白名单抽烂了。
这是 L4 前瞻账本之外的**回顾性应期数据**，后续可做「大运引动」检验。

## 四、裁判：天干口径 vs 8字口径

**判据 = 压缩法（哪个尺子把可能性空间压得更小）。20 个趋势检验 ⇒ 多重比较红线 z≈2.81 + 分半复现。**

| 候选 | 全样本 z | 分半(z) | 判定 |
|---|---|---|---|
| 劫财（天干尺）| 2.63 | 1.10 / 0.65 | 虚（靠 n=10 格）|
| 偏印（天干尺）| −2.23 | −2.76 / −0.44 | 不稳 |
| **偏财（8字尺）** | **−2.84** | **−1.82 / −2.25** | **成立** ✅ |

**成立的唯一一条（财域凶率，基线 39.7%）**：

```
偏财 8字口径:  0档 60%(47) → 1档 37%(82) → 2档 38%(61) → 3档 28%(47)   趋势 z=−2.84
偏财 天干口径: 0档 40%(161) → 1档 44%(66)                                   趋势 z=−0.44（测不出）
正财 8字口径:  0档 32%(56) → 1档 40%(83) → 2档 41%(64) → 3档 50%(34)   趋势 z=+1.59（同向但未过线）
正财 天干口径: 0档 40% → 1档 38%                                            平的
```

**读法**：**偏财（流通/众人之财）越多 → 财域结果越好；正财（受制之财）越多 → 越耗身破财。**
两条经典区分**只在把地支藏干算进来后才可见**——天干口径两行全平。

## 五、裁定

1. **要不要改口径** → **改，但不是"换"是"并排"，8 字口径立为主尺。**
   依据：①它在唯一可测的域上压出了天干尺压不出的梯度，且过最严校正线 + 分半复现；
   ②纯天干尺与自家经典自相矛盾（子平取用神以月令=地支为准）；
   ③《千里命稿》韦千里「当以干支并看」——两套语义并存（天干=表面/显，地支=实力/根）。
2. **诚实面**：这是**单点证据**（1 域 × 1 十神），不是全面胜利。其余 17 个检验全灭，
   其中天干尺的 2 个疑似发现正是「20 次里该出现的假阳性」——**多重比较校正救了这一步**。
3. **暴露的真瓶颈**：多数事类被词表**单极化** ⇒ 结构性天花板，永远测不出：
   - 功名事业基线凶率 **3.9%**（几乎只有"显贵"才被记下）
   - 刑灾官非 **100% 凶**、寿元健康 **96.5% 凶**（词表只有凶向）
   ⇒ 下一步必须给词表**补双向**，否则只有「财」「婚姻」两域可用。
4. **保留待验假设**：`tonggen`（根落哪一柱：年/月/日/时）是否比"有无根"更有效——
   已留列，待出口再修后一起测。
