# 十神尺子调查：天干 vs 地支（2026-10-07）

> 触发：用户指出「四柱算十神是不是只算了天干？有些流派确实这么算，但另一些流派说一柱的能量主要由地支决定，天干只是表面体现。要不要改，需要调查。」
> 用户只给方向，做法由 see 自定。**做法＝流派取证 + 数据当裁判。**

## 一、现状核实（确定）

手工验算 + 全库统计双双确认：

- `case_features.shishen_config` 全库 **2322 例，十神计数总和恒等于 4**。
- 手工验 `丁巳|壬子|丙午|己亥`（日主丙）：丁=劫财、壬=七杀、**丙=比肩（日干自计）**、己=伤官 → 4 项，吻合。
- 十神键只有 4 个来源 ⇒ **只取年干/月干/日干/时干；地支（含藏干）权重为零。**

⇒ **用户判断正确。** 现状口径 = 纯天干尺。

## 二、流派取证（分歧是真的，且两派都有原话）

| 立场 | 原文 | 出处 |
|---|---|---|
| **地支主能量** | 「**支为根，干为苗，干透不如支藏**，但须过程得地，否则，地位虽高而不显。」 | 《穷通宝鉴》徐乐吾注（书库行 8071） |
| 地支主能量 | 「**干为苗，支为根，干必须通根，方有力也。**」 | 《穷通宝鉴》（行 8998） |
| 地支主能量 | 「凡行运，在干兼用地支之神，在支则弃天干之物。盖**大运重地支**。」 | 《三命通会》（行 649） |
| 分场景 | 「大运譬所到之地，故**重地支**，未尝无天干。太岁譬所遇之人，故**重天干**，未偿无地支。」 | 《原注滴天髓》（行 712） |
| **两派并存** | 「如**以天干为用**，成气成合，而地支之神，虚脱无气……如**以地支为用**，成助成合，而天干之神，游散浮泛」 | 《原注滴天髓》（行 506） |
| 干支并看 | 「有谓流年，**重天干**。亦有以天干为上半年，地支为下半年，**皆非的论。当以干支并看**，最较精确。」 | 《千里命稿》韦千里（行 2024） |
| 旁证 | 「先定地支，后配天干，**以定应期的地支为主**，兼看天干定应期」 | 《神奇之门》张志春（奇门断应期，行 5516） |

- 「**通根**」词频 189 次：子平真诠评注 79、滴天髓闡微 50、穷通宝鉴 57、渊海子平 1、千里命稿 1。
- 旁证（子平法自身）：**取用神以「月令」为准，月令＝地支**。若天干才是主能量，用神就该取月干。

**取证结论**：不是「谁对谁错」，是**口径选择**。但**纯天干尺与我们自己依据的经典自相矛盾**。

## 三、数据裁判（判不出胜负，但判出了更重要的事）

设计：**嵌套比较**（子集切域，非加格子 ⇒ 无「格子多就拟合好」的作弊）。
判据：`凶率`；样本 = verdict 已填的 722 例；脚本 `ruler_ab.py`（现状口径复现不一致 **0 例**，尺子可信）。

**判决：证据不足。不能判「必须改」，也不能判「不用改」。**

## 四、为什么判不出来（关键）

不是地支没用，是**「结果出口」分辨率太低**——测量学常识：**先修分辨率最低的那一端。**

- `verdict` 只填 **722/2322 = 31.1%**
- 吉凶桶是**关键词粗分类**，且基线本身歪（凶 43.9% vs 吉 17.0% ⇒ 桶偏凶）
- 「凶」把 **车祸 / 入狱 / 离婚 / 失明** 全糊成一类 ⇒ 结果变量糊成一坨，自变量的细微作用全被淹没

⇒ 自变量尺子再准，**出口糊了就测不出任何东西**。

## 五、采取的动作（干支双尺并行，不覆盖旧字段）

理由：《千里命稿》「**当以干支并看**」——不是替换，是并行。理由是**既不能留纯天干尺（已知残缺），也不能丢掉天干信息（表/显）**。

已给 `case_features` **增补 3 列**（旧 `shishen_config` 一律不动，可回滚；备份 `jinxiang.db.bak-20261007-1126`）：

| 新列 | 含义 |
|---|---|
| `shishen_quan` | 8 字口径：4 天干 + 4 地支**全部藏干** |
| `shishen_benqi` | 8 字口径（本气版）：4 天干 + 4 地支**本气** |
| `tonggen` | `{"七杀":["年","月"],...}` — 各十神**根落在哪几柱**（含日支＝夫妻宫） |
| `shishen_ruler_ver` | 1 = 已用新尺子重算 |

脚本 `build_ruler8.py`。校验：天干总量 2322×4 = **9288** ✓；8 字总量 **31064**（每例 13.4 项 = 4 干 + 9.4 藏干）✓；手工逐字复核 1 例全对 ✓。

**注意**：新字段带来新的判据空间——「通根**有无**」可能不如「通根在**哪一柱**」有效（年月＝早年/祖辈，日＝夫妻宫，时＝晚年/子女）。`tonggen` 就是为这个留的。
