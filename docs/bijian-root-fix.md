# 比肩修根实录（2026-10-07）

## 一句话
库的十神抽取器把**日干自己**也拿去数了十神，而 `ss(日干, 日干)` 恒等于「比肩」⇒
全库每一例比肩 ≥1，「比肩=0」「比劫=0」这类条件**永远不成立**。
整条比劫轴因此白跑，且**没有任何报错**。本轮把它连根拔掉。

## 一、定位（三级追源）

| 层 | 位置 | 写法 |
|---|---|---|
| 读数层 | `build_ruler8.py` 第 79 行 | `for g in gs:` ← `gs` = 四柱天干，含 `gs[2]`＝日干 |
| 判定层 | 同文件 `ss(rz, rz) == 比肩` | 同五行同阴阳 ⇒ 日干永远给自己安一枚比肩 |
| **产线源头** | `scripts/extract_features.py` 第 341 行 | `for p in p_list: ss[shishen(day_p[0], p[0])] += 1` ← 循环含日柱 |

**三级都指向同一个错**：日干是**参照点**，不该被安十神（月亮不照自己）。
`shishen_config`（平台原列）也带同一习惯 ⇒ 这是**原库口径**，不是笔误。

## 二、修根动作

`fix_shishen_root.py`（v2）：
1. 备份库 → `jinxiang.db.bak-20261007-bijian`；
2. 天干循环 **跳过第 3 位**（日干）重算；
3. 写 `shishen_quan` / `shishen_benqi` / `shishen_tiangan`，`shishen_ruler_ver = 2`；
4. **旧值留档**：把旧比肩数存入 `bijian_v1`（不删证据）；
5. 打不变式核对（见下）。

`build_ruler8.py` **加废弃闸**：无 `--force-v1` 直接 exit 1，防止有人重跑把它盖回 v1。

## 三、验证四层

| 层 | 检查 | 结果 |
|---|---|---|
| L1 不变式 | 「新值 == 旧比肩 − 1」逐例核对 | **差异例数 = 0** ⇒ 证明确实**只**差在比肩，日干从未被算成别的神 |
| L2 分布 | 比肩 0 组例数 | **0 → 587（25.3%）**，落进其余九神的 23.7%~29.9% 区间 |
| L3 结构 | 槽位总和 | min 8~max 16 / 中位 14 → **7~15 / 中位 13**（恰降 1） |
| L4 手算 | 抽 case 1「丙辰 辛丑 丁卯 庚戌」日主丁 全字逐格核 | 戌藏丁→比肩 **1**；辰戊+戌戊→伤官 2；丑己→食神 1；丑辰二癸→七杀 2；辰卯二乙→偏印 2；辛+丑辛+戌辛→偏财 3；正官/正印 0 —— **与库新值逐格相符** |

**结果侧零变动**：打分器主表 42 行**无一变动**——因为当初兜底的「−1」恰好等价。
修根的价值不在改数字，而在**库不再撒谎**＋「−1」这个隐藏约定被取消。

## 五、沉淀出的三条纪律

1. **兜底要写成条件式，不要写成常数**——常数会在修根那天变成新 bug（双重扣减照样跑得通、照样出 z）。
2. **排除要看位置，不要看字面**——`同字即同物`在重复字面前静默错一格。
3. **修根后必须回收全部兜底补丁**——搜全仓 `-1` / `- 1` 与字段名，一处不落。
